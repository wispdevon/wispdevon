# schoolcrm

A Devon Labs repository reserved for a school CRM project.

## Status

This repository is a placeholder: the public default branch contains a README,
a license, and `.gitignore`, with no application source or installation workflow.
It is not a deployable school-management product.

No features, data model, authentication flow, or supported platforms are defined
here yet. Follow the repository for future source updates rather than treating
the name as a feature promise.

## Discussion

Use [Issues](https://github.com/wispdevon/schoolcrm/issues) to discuss a proposal.
Do not upload student records or other personal school data. Contribution and
setup instructions can be added when an implementation exists.
